# Реализация блока "Наши партнеры"

## Описание задачи
Создан блок "Наши партнеры" на странице celebrations с двумя карточками партнеров:
- Пиццерия "My Chef"
- Поле чудес

## Выполненные изменения

### 1. HTML структура
Добавлена секция `partners__section` в файл `page-celebrations.php` (строки 531-571):
- Контейнер с заголовком и подзаголовком
- Две карточки партнеров с изображениями, описанием и ссылками
- Использованы шаблонные изображения Rectangle 78.png и Rectangle 79.png

### 2. CSS стили
Добавлены полные стили для блока партнеров (строки 1672-1905):
- Адаптивный дизайн с Grid Layout
- Анимации при наведении (hover effects)
- Градиентный фон секции
- Мобильная адаптация для экранов 768px и 480px
- Стилизованные кнопки с анимацией

### 3. Функциональность
- Ссылки открываются в новой вкладке (target="_blank")
- Интерактивные элементы с плавными переходами
- SVG иконки для кнопок "Перейти на сайт"

## Технические детails

### Используемые изображения:
- `src/img/png/Rectangle 78.png` - для Пиццерии "My Chef"
- `src/img/png/Rectangle 79.png` - для "Поле чудес"

### Ссылки партнеров:
- My Chef: https://mychef.ru
- Поле чудес: https://polechudes.ru

### Цветовая схема:
- Основной цвет: #5534F5 (фиолетовый)
- Акцентные цвета: #F2A531 (оранжевый), #FFC548 (желтый)
- Фон секции: градиент от #f8f9ff до #ffffff

- Десктоп: две карточки в ряд
- Планшет (768px): одна карточка в ряд
- Мобильные (480px): уменьшенные размеры элементов
